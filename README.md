# Nexora

Sitio web de una página para presentar la empresa Nexora. Está hecho con HTML, CSS y JavaScript nativo; no requiere instalación de dependencias ni un proceso de compilación.

## Estructura

| Archivo | Función |
| --- | --- |
| `index.html` | Contenido, navegación, servicios, presentación y contacto. |
| `styles.css` | Diseño, colores y adaptación a distintos tamaños de pantalla. |
| `script.js` | Aparición suave de las secciones al desplazarse. |
| `assets/nexora-logo.png` | Símbolo de Nexora usado en la portada y como icono del sitio. |
| `assets/nexora-brand.jpg` | Imagen de marca usada en «Sobre Nexora». |

## Vista local

Abre `index.html` en un navegador. Para publicar el sitio, conserva `index.html`, `styles.css`, `script.js` y la carpeta `assets` con la misma estructura.

Las animaciones son decorativas. Si JavaScript no está disponible, el contenido sigue visible; si la persona prefiere reducir el movimiento, las animaciones se desactivan.

- Cambia textos y destinos de enlaces en `index.html`.
